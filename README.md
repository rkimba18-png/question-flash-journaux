# Question Flash — journaux

Dépôt privé alimenté automatiquement par l'appli Question Flash.

- `journaux/AAAA-MM-JJ.txt` : journal du jour (envoyé chaque soir).
- `stats/AAAA-MM-JJ.csv` : statistiques du jour.
- `verdicts/AAAA-MM-JJ.tsv` : réponses tapées dont le verdict a été corrigé (« C'était juste » / « C'était faux »).
- `regles/regles.json` : dictionnaire d'abréviations, synonymes et seuils, régénéré par Claude à partir des journaux et téléchargé par l'appli au démarrage.
